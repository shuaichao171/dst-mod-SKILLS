# DST 模组测试矩阵

## 最小必测

| 维度 | 场景 |
| --- | --- |
| 加载 | 默认配置、非默认配置、禁用再启用 |
| 玩家 | 主机玩家、远端客户端 |
| 服务器 | 本地主机、专用服务器 |
| 分片 | Master、Caves、往返迁移 |
| 生命周期 | 生成、睡眠、唤醒、移除 |
| 存档 | 保存、关服、重载、回滚 |
| 网络 | 加入中、断线重连、高延迟 |
| 兼容 | 单独启用、交换加载顺序 |

## 错误记录

记录第一条相关错误、完整堆栈、游戏版本、模组版本、配置、世界类型、发生端和精确复现步骤。

## 结果标签

- 已运行通过：实际执行且结果符合预期。
- 静态通过：语法或代码路径检查，无游戏运行证据。
- 需要游戏验证：需要渲染、多人或引擎行为。
- 未通过：保留日志与最小复现。
- 未执行：说明原因，不用推测替代。

## 高风险专项

网络功能增加恶意 RPC、重复请求与目标失效测试。持久化功能增加旧 schema 和缺失引用。世界生成功能增加多个种子。UI 增加手柄、长文本与 HUD 重建。Boss 增加中途保存和玩家全灭。
