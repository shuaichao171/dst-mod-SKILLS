# 更新影响分级

## 顺序

1. 比较 modutil、mods 和入口加载。
2. 比较 entityscript、组件生命周期和 Replica。
3. 比较 Action、SG、Brain 与 Behaviour。
4. 比较 netvar 与 RPC。
5. 比较目标模组依赖的原版 Prefab 和字段。
6. 比较世界生成和 UI 类。
7. 运行目标模组回归矩阵。

## 分级

| 等级 | 含义 |
| --- | --- |
| 必然破坏 | 符号删除、签名不兼容、目标文件或状态不存在 |
| 高风险 | 调用顺序、主客机边界、保存或网络契约改变 |
| 行为变化 | API 仍存在，但数值、标签、事件或默认值改变 |
| 低风险 | 目标模组不依赖的内部内容变化 |
| 未确认 | 只有哈希差异，尚未做语义检查 |

快照只帮助收窄范围，不能替代语义差异和游戏回归。
